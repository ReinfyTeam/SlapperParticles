# SlapperParticles
[![](https://poggit.pmmp.io/shield.state/SlapperParticles)](https://poggit.pmmp.io/p/SlapperParticles)
[![](https://poggit.pmmp.io/shield.api/SlapperParticles)](https://poggit.pmmp.io/p/SlapperParticles)<br>
Slappers can now have particles.

# Features
- Ability to configure the particle colors displayed around Slappers.

# Disclaimer
This plugin is designed for PocketMine-MP. If you are using a fork or spoon of PocketMine-MP, please report issues to that project instead.

# How to Install?
- You must have the Slapper plugin. You can download it from [Poggit](https://poggit.pmmp.io/p/Slapper/).
- Just put this plugin in your `plugins/` folder, and it should work!<br>
- You can configure the plugin in `plugin_data/SlapperParticles/config.yml`.
